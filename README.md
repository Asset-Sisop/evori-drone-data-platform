# EVORI Drone Data Platform — MVP

MVP веб-платформы для единого сценария работы с данными аэросъёмки БПЛА: **проект → загрузка данных → импорт обработанного георезультата → карта → измерения → отчёт**.

Проект реализован по ТЗ EVORI и специально ограничен объёмом MVP: собственного фотограмметрического движка, полноценного AI/CV и промышленной инфраструктуры нет.

## Реализовано
- JWT-авторизация, вход/выход.
- Создание и список проектов с параметрами из ТЗ.
- Загрузка JPG/JPEG, PNG, GeoTIFF, ZIP, CSV и GIS-файлов.
- Отдельный сценарий **«Импорт результата»**: готовый результат обработки прикрепляется к выбранному проекту (вариант В из ТЗ).
- GIS-интерфейс Leaflet + OpenStreetMap.
- Базовые измерения расстояния и площади через Leaflet Draw.
- Сохранение измерений в проекте.
- Генерация печатного HTML-отчёта, который сохраняется/печатается в PDF браузером.
- Docker Compose для повторяемого запуска.
- Тесты API и CI workflow.

## Запуск
Требуются Docker Desktop и Git.

```bash
docker compose up --build
```

Открыть: http://localhost:5173
API: http://localhost:8000/docs

Демо-пользователь:
- login: `demo`
- password: `demo123`

**Перед передачей заказчику обязательно заменить `EVORI_SECRET` и демо-пароль.**

## Локальный запуск backend
```bash
cd backend
python -m venv .venv
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Приёмочный сценарий
1. Войти.
2. Создать проект.
3. Заполнить параметры объекта.
4. Загрузить тестовые данные.
5. Нажать «Импорт результата» и выбрать GeoTIFF/GIS-результат.
6. Открыть карту.
7. Нарисовать линию и полигон для измерений.
8. Нажать «Сохранить измерения».
9. Нажать «Отчёт» и распечатать страницу в PDF.

## Архитектура
- `frontend/` — React + Vite + Leaflet.
- `backend/` — FastAPI, JWT, файловое хранилище и API.
- MVP использует SQLite для демонстрационного запуска без инфраструктурных зависимостей. Архитектура отделена так, чтобы PostgreSQL/PostGIS можно было подключить на следующем этапе.
