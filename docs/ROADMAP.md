# Roadmap после MVP

1. PostgreSQL + PostGIS.
2. Настоящий GeoTIFF tile/render pipeline.
3. S3-compatible storage.
4. Celery/RQ + Redis для фоновой обработки.
5. Интеграция фотограмметрического решения API/CLI.
6. GeoJSON/LAS/LAZ/DSM/DTM/3D.
7. Change Detection.
8. AI/CV: дефекты, сегментация, классификация.
9. Кабинет заказчика, роли, API-интеграции.
10. Production security, audit log, backups and observability.
