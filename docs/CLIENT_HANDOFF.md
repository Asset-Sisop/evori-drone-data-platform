# EVORI — Client Handoff

## Статус

MVP подготовлен для технического review и демонстрации по Техническому заданию EVORI Drone Data Platform.

## Что можно проверить

1. Авторизация.
2. Создание и повторное открытие проекта.
3. Загрузка исходных материалов.
4. Импорт уже обработанного результата по варианту В.
5. Отображение GeoJSON и GeoTIFF на карте.
6. Измерение расстояния и площади.
7. Сохранение измерений.
8. Формирование печатного HTML-отчёта и сохранение его в PDF.
9. Запуск проекта через Docker Compose.
10. Исходный код и техническая документация в GitHub.

## Быстрый demo

Для проверки без реального набора данных используется файл sample-data/demo.geojson.

После запуска:

- открыть frontend;
- войти demo / demo123;
- создать проект;
- выбрать «Импорт результата»;
- выбрать sample-data/demo.geojson;
- проверить появление полигона на карте;
- нарисовать линию и полигон;
- сохранить измерения;
- открыть отчёт.

## Что сознательно не входит

Собственный фотограмметрический движок, полноценный AI/CV, Change Detection, LiDAR, сложная 3D-визуализация, промышленная отказоустойчивость, обработка десятков и сотен гигабайт, CRM/ERP и сложная ролевая модель не входят в MVP в соответствии с ТЗ.

## Технические замечания

MVP использует SQLite и локальное файловое хранилище для автономной демонстрации. Для следующего этапа рекомендуется PostgreSQL/PostGIS, объектное хранилище, очередь обработки, аудит, резервное копирование, upload limits и production reverse proxy.

Демо-логин предназначен только для приёмочной демонстрации. Перед production необходимо заменить секрет JWT и учётные данные.

## Проверка качества

Backend syntax check выполнен локально.

Полный frontend production build в текущей среде локально не запускался из-за отсутствия доступа к npm registry. Для чистого окружения сборка добавлена в GitHub Actions и выполняется на push/pull request.

## Результат

Репозиторий содержит исходный код, инструкции запуска, архитектуру, матрицу приёмки, demo-сценарий, roadmap и перечень используемых компонентов.
