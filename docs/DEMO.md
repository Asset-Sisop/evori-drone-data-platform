# Сценарий демонстрации заказчику

1. Открыть `http://localhost:5173`.
2. Войти `demo / demo123`.
3. Создать проект «Тестовый карьер EVORI».
4. Загрузить JPG/PNG или тестовый GeoTIFF.
5. Выполнить «Импорт результата» для готового GeoTIFF.
6. На карте показать навигацию и масштабирование.
7. Нарисовать линию — показать расстояние.
8. Нарисовать полигон — показать площадь.
9. Сохранить измерения.
10. Открыть отчёт и выбрать «Печать → Save as PDF».
