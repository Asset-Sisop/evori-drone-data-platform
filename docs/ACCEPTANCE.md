# Матрица приёмки MVP

Матрица сверена с Техническим заданием EVORI Drone Data Platform.

| Требование ТЗ | Реализация | Проверка |
|---|---|---|
| Авторизация | JWT login + logout | demo/demo123, кнопка «Выйти» |
| Проект | Project API + UI | Создание проекта с полями ТЗ |
| Список проектов | Project list + open | Выбрать ранее созданный проект |
| Загрузка | multipart upload | JPG/JPEG, PNG, GeoTIFF, ZIP, CSV, GeoJSON/JSON |
| Геоданные | Leaflet + OpenStreetMap | Панорамирование и масштабирование |
| Результат | Import Result | Импорт GeoTIFF или GeoJSON |
| Отображение результата | GeoJSON layer / GeoTIFF ImageOverlay | После импорта результат отображается на карте |
| Автоматизация | Вариант В | Результат автоматически привязывается к project_id |
| Расстояние | Leaflet Draw | Нарисовать линию |
| Площадь | Leaflet Draw | Нарисовать полигон |
| Сохранение | Measurements API | «Сохранить измерения» |
| Отчёт | Авторизованный HTML print-ready | «Отчёт» → печать браузера → PDF |
| Исходный код | GitHub repository | Полный source в main |
| Архитектура | Backend/frontend separation | docs/ARCHITECTURE.md |
| Запуск | Docker Compose | docker compose up --build |

## Приёмочный сценарий

1. Авторизоваться.
2. Создать проект.
3. Указать объект и основные параметры.
4. Загрузить исходные данные.
5. Нажать «Импорт результата» и выбрать sample-data/demo.geojson либо реальный GeoTIFF.
6. Убедиться, что результат появился на карте.
7. Измерить расстояние и площадь.
8. Нажать «Сохранить измерения» и убедиться, что рядом с измерениями появился знак сохранения.
9. Нажать «Отчёт» и сохранить страницу как PDF.
10. Выйти и снова войти — проекты должны остаться доступны пользователю.

## Ограничения MVP

- GeoTIFF отображается в браузере для распространённых CRS: EPSG:4326, EPSG:3857 и UTM EPSG:326xx/327xx.
- Для промышленной эксплуатации следует перейти на PostgreSQL/PostGIS, объектное хранилище, очереди обработки, аудит и резервное копирование.
- Полноценная фотограмметрия, AI/CV, Change Detection, LiDAR, 3D и обработка десятков/сотен ГБ сознательно не входят в MVP согласно ТЗ.
